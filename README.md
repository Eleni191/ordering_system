 Restaurant Ordering System
 About the Project

The Restaurant Ordering System is a desktop application developed using Java and JavaFX, with CSS for styling and MySQL for database management.

The system is designed to simplify restaurant operations by providing an interactive graphical user interface for managing food orders and restaurant-related information. It connects to a MySQL database to store and manage application data efficiently.

This project demonstrates the use of object-oriented programming, desktop application development, database connectivity, and user interface design.

 Technologies Used
Java — Application logic and functionality.
JavaFX — Graphical user interface (GUI).
CSS — Styling and UI customization.
MySQL — Database management and data storage.
JDBC — Connecting the Java application to the MySQL database.

 Features

User-friendly desktop interface.

Interactive screens built with JavaFX.

Styled components using CSS.

MySQL database integration.

Data storage and retrieval using JDBC.

Restaurant ordering functionality.
